# UTS Data Mining - Wine Quality Prediction

Project UTS Data Mining mengenai klasifikasi kualitas wine menggunakan beberapa algoritma machine learning.

## Model yang Digunakan
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- KNN

## Hasil
Berdasarkan hasil cross validation, model Random Forest memperoleh performa terbaik dalam memprediksi kualitas wine.
